# نموذج منصة معهد بوابة المستقبل العالي للتدريب — ديمو العرض

نموذج عربي تفاعلي (RTL) يجمع: الموقع العام، بوابة المتدرب، بوابة المدرب، وبوابة الإدارة والتشغيل.
**نموذج عرض وليس نظام إنتاج** — البيانات اصطناعية وتُحفظ على المتصفح فقط.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح: http://localhost:5173

- بناء نسخة العرض: `npm run build` ثم `npm run preview`
- إعادة البيانات الأصلية: «إعادة ضبط الديمو» أسفل القائمة الجانبية في أي بوابة.

التقنيات: React + TypeScript + Vite 6، خط IBM Plex Sans Arabic محلي (fontsource)، أيقونات Lucide، مصدر بيانات واحد (Context) مع حفظ محلي.

## سيناريو العرض (7–10 دقائق)

1. الموقع `/` ← «استكشف البرامج» ← «دبلوم إدارة المشاريع» ← «قدّم الآن» (اسم + بريد) ← يظهر الطلب للإدارة.
2. «دخول المنصة» ← متدرب ← «أكمل الدرس» (الجدولة الزمنية) ← «إكمال الدرس»: التقدم 7/12 (58%) ← 8/12 (67%).
3. لوحة المتدرب ← «الواجبات» ← «تسليم» واجب «إعداد وثيقة نطاق مشروع» واختيار ملف.
4. المبدّل في الرأس ← مدرب ← «تنتظر التصحيح» ← تصحيح محمد بـ 18/20 مع ملاحظة ← «اعتماد ونشر».
5. «نشر إعلان للشعبة» ← العودة للمتدرب: الدرجة والملاحظة والإعلان ظاهرة.
6. إدارة ← «مراجعة طلبات القبول» ← قبول المتقدم وإسناده لشعبة PM-01.
7. «الأعذار» ← قبول عذر محمد عن اللقاء السادس: الغياب 16.7% ← 0%.
8. تشغيل المعهد ← نقل مهمة عبر «نقل إلى…» ← «الإجازات» اعتماد ← «التقارير» تنزيل CSV.

## ما يعمل فعليًا داخل الديمو

- مصدر بيانات واحد لكل الأدوار: التقدم، التسليم، الدرجة، الإعلان، الحضور، القبول، الأعذار، الطلبات، المهام والإجازات تنعكس فورًا بين البوابات.
- الأعداد والمؤشرات مشتقة من البيانات (24 متدربًا، 3 مدربين، 4 موظفين، 4 برامج، 3 شعب نشطة، 6 لقاءات منعقدة + 3 قادمة للشعبة الرئيسية، 4 واجبات، 3 طلبات قبول، 3 طلبات خدمات، 2 عذر، 8 مهام).
- قاعدة الغياب المعلنة: الغياب غير المعذور ÷ اللقاءات المنعقدة؛ التأخير لا يُحتسب غيابًا؛ العذر المقبول لا يدخل النسبة. حد التنبيه 25% إعداد تجريبي قابل للتعديل من الإدارة، ولا حرمان تلقائي.
- تنزيل CSV حقيقي (متوافق مع Excel العربي) من القوائم المصفاة، والطباعة عبر نافذة الطباعة.

## ما هو محاكاة

- لا تسجيل دخول ولا صلاحيات: مبدّل الأدوار أداة عرض.
- اللقاء المباشر: غرفة انتظار ومعاينة دون Zoom/Teams، والحضور يُرصد يدويًا.
- الملفات: يُحفظ الاسم والحجم والتاريخ فقط، دون رفع.
- الفيديو: مساحة معاينة معلنة (لا ملفات فيديو مرفقة).
- البطاقة الرقمية والشهادة: معاينات بعلامة «معاينة تجريبية» دون QR أو تحقق.
- الأسعار: وسم «سعر تجريبي»، لا دفع.
- لا تُرسل أي رسالة أو بريد. الحالة محفوظة في `localStorage` لهذا المتصفح فقط.
